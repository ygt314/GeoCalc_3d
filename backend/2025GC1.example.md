# 示例几何题:2025GC1

这是一道示例题目存档(2025 高考全国一卷几何题改编),演示本计算器的能力。

## 题目内容

- 点: A, B, C, D(底面四边形)+ P + O(空间点)
- 未知数: x_O, y_O, z_O(O 的坐标)
- 条件: OB = OD, OB = OC, OB = OP(O 到 B/D/C/P 距离相等)

## 求解结果(验证过)

```
OB = √(2√3 + 8) / 2   ← 含嵌套根号(sqrtdenest 处理)
xO = √2 / 2           ← O 的横坐标
```

## 用法

应用内"从文件加载"选择本文件即可。
或用 Python 直接读:

```python
import pickle, sys
sys.path.insert(0, 'src')
with open('2025GC1.gc.pkl', 'rb') as f:
    p = pickle.load(f)
print(p.solve('OB'))   # → ['OB = √(2√3+8)/2']
```
